# v0.1.0 — six behavioral scenarios for proactive super-agents

> **Unofficial, not affiliated with DeepSeek.** The name identifies the design
> family this suite tests. This repository contains no DeepSeek code, logos, or
> branding.

v0.1.0 is the first public behavioral matrix for
[deepseek-superagent-bench](https://github.com/Mikkey-f/deepseek-superagent-bench):
a reproducible, offline-by-default conformance suite for proactive super-agent
implementations.

## Highlights

- **Six core scenarios**: C1 direct request, C2 duplicate delivery, C3
  concurrent duplicate delivery, C4 mid-flight restart, C5 unauthorized sender,
  C7 after-settle restart.
- **Two real subjects**, pinned by commit: opensuperagent (black-box HTTP) and
  LofiSu deepseek-super-agent (in-process Runtime).
- **A fixture and three negative controls** that prove the evaluator can fail,
  not only pass.
- **Capability-gated fairness**: a missing capability makes a scenario
  `not_tested`, not a failure.
- **Raw traces and repeat aggregation**: flaky results are surfaced, not
  averaged away.
- **No real model, API key, GitHub, or Feishu dependency** in the default suite.

## Evidence

The pinned snapshot is in
[docs/results/v0.1.0](https://github.com/Mikkey-f/deepseek-superagent-bench/tree/main/docs/results/v0.1.0):

- opensuperagent `0.1.1` @ `a9f9b7efc3ca8e055de2ef9fa0595155e4e108ed`
- deepseek-super-agent (LofiSu) `0.1.0` @ `e705e872796ed1900fa6b42093136e577861de7f`
- Node v22.14.0, Windows 11, 3 repeats per scenario × subject
- **18/18 scenario×subject combinations pass**, 3/3 repeats
- C2/C3/C4/C7 each assert one ticket; C4 records `midFlightObserved: true`
- The negative controls fail C2/C5/C7 exactly as intended

This is a behavioral matrix, not a ranking. A pass means the observable
assertions held for this run, at this commit; it is not a production-readiness
claim.

## Quickstart

```bash
git clone https://github.com/Mikkey-f/deepseek-superagent-bench.git
cd deepseek-superagent-bench
npm install
npm run bench:fixture      # offline; no subject repositories needed
```

For real subjects, place their checkouts next to this repository and run:

```bash
npm run prepare:subjects
npm run bench:core
```

See the [README](https://github.com/Mikkey-f/deepseek-superagent-bench#readme)
and [SPEC](https://github.com/Mikkey-f/deepseek-superagent-bench/blob/main/docs/SPEC.md).

## Known limitations

- Scripted mock model and synthetic events; model quality, task success,
  latency, and cost are not measured.
- C4 is a graceful stop/start with a delayed worker, not a hard crash with
  unflushed state.
- In-process LofiSu outbound is captured from a durable outbox, not a real
  channel delivery.
- CI exercises the fixture and negative controls only; real-subject matrices are
  local and commit-pinned.
- All 18 combinations currently pass; the suite demonstrates conformance on
  these scenarios, not a single winner.
